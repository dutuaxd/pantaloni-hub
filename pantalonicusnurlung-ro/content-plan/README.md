# PSL Fashion topical map

Fisier principal: `topical-map.json`.

Versiunea curenta este extinsa la scara mare conform noilor tinte:

- 50.211 URL-uri totale in plan.
- 50.200 URL-uri indexabile teoretic.
- 420 pagini P1 cu content brief draft-ready.
- 11 oportunitati secundare pentru femei, marcate neindexabile pana la confirmare Search Console.

Important: nu publica toate cele 50k URL-uri simultan. Publicarea trebuie facuta in valuri, cu QA editorial, logica de internal linking si monitorizare in Google Search Console.

Reguli de publicare:

1. Publica intai doar paginile `P1`.
2. Nu publica automat tot setul P2/P3 fara QA editorial si verificare Search Console.
3. Fiecare pagina trebuie sa pastreze `primaryKeyword` unic si campul `semanticDifferentiator`.
4. Inainte de publicare, verifica `avoidCannibalizationWith` si actualizeaza linkurile interne.
5. Paginile din hub-ul `Femei secundar` raman oportunitati neindexabile pana cand Search Console confirma impresii si cerere.
6. CTA comercial permis: `Vezi stocul actualizat pe AtelierAXD` sau `Verifica disponibilitatea pe AtelierAXD`.
7. Nu adauga preturi, reduceri, disponibilitate locala sau superlative comerciale neverificate.

Valuri recomandate:

- Wave 1: P1, hub-uri si ghiduri pilon.
- Wave 2: P2, extindere semantica validata.
- Wave 3: P3, long-tail util publicat gradual.
- Wave 4: P4, doar oportunitati demonstrate prin Search Console.
