# PSL Fashion content

Structura aceasta este pentru continut editorial data-driven. Site-ul actual foloseste inca `src/data` pentru compatibilitate cu rutele indexate, iar fisierele din acest folder pot fi migrate treptat in pipeline-ul Astro.

- `articles/` pentru articole evergreen.
- `news/` pentru note editoriale si trenduri.
- `guides/` pentru ghiduri de marimi, materiale, croieli si culori.
- `outfits/` pentru tinute.
- `products/` pentru recomandari informative AtelierAXD.
- `categories/` pentru hub-uri si taxonomii.
